{# The docx template for this version. The loop this card exists to make obvious: download the starter, brand it in Word, upload it back. The starter already carries every tag the spec implies, so the rule builder never types a section key — which is what makes most of the errors below unreachable rather than merely reported (ARCHITECTURE §15.5). Problems and gaps are different severities on purpose. A tag naming a section that does not exist renders as nothing and is refused. A section the template never mentions is allowed, because leaving an internal section out of the customer's copy is a real thing people do — it is said out loud and permitted. The card re-lints what is attached every time it renders, because what invalidates a template happens elsewhere: publishing a new version carries the template forward, and a spec that grew a section has a template one chapter short. A card that reported only what was true at upload would go stale exactly when it matters. #}
